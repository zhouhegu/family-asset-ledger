# 数据格式

## 存储与备份

浏览器存储键为 `family_asset_ledger_v2`。JSON 备份标识为 `app: family_asset_ledger`，导出版本为 `2.3`；兼容读取 `1.0`、`2.0`、`2.1`、`2.2`、`2.3` 和无版本字段的旧本地数据。

语言偏好单独保存在 `family_asset_ledger_language`，值为 `zh-CN` 或 `en`，不写入账本备份。语言切换只影响界面，保留用户填写的文本、成员 ID、交易原因内部值、币种和所有金额。示例预览使用打开预览时的语言；已有账本不会自动改名。

外观偏好单独保存在 `family_asset_ledger_theme`，值为 `system`、`light` 或 `dark`，不写入账本备份。默认 `system` 跟随设备主题，手动选择优先于系统设置；切换外观不修改账本或未保存的表单。

| 字段 | 含义 |
| --- | --- |
| `currency` | 账本统一币种，大写三字母代码，如 `CNY`、`USD`、`EUR` |
| `members` | 成员显示姓名与稳定 ID |
| `assets` | 资产与负债账户，可为空数组 |
| `history` | 按 `all`、`p1`、`p2`、`share` 分组的历史快照 |
| `logs` | 各账户的余额变动记录 |
| `targets` | 四类金融资产的目标上下限 |
| `lastBackupTime` | 最近备份或恢复时间，可为空 |
| `savedAt` | 数据写入时间 |

备份另有 `backupAt` 字段。旧备份缺少成员时沿用当前成员配置，缺少历史和流水时使用空集合，不与当前账本混合。

所有资产、负债、历史和流水共用一个币种，从内置币种列表中选择。更改币种不进行汇率换算，不改写任何金额或产生流水。顶部币种选择在存储写入成功后生效，写入失败时恢复原选项。成员姓名单独保存。恢复旧版或无版本备份时，缺少币种按原格式解释为 `CNY`；`2.2` 和 `2.3` 备份必须包含有效币种，否则整份备份被拒绝。示例预览沿用当前币种，预览期间不能修改币种。

## 成员与金额

`p1`、`p2` 是稳定成员 ID，`share` 是共有归属，`all` 仅表示汇总视角。修改姓名不改变账户归属或历史金额。

`assets[].amount` 对资产和负债均为非负数，负债同时使用 `category: debt` 和 `isLiability: true`。净资产等于非负债资产之和减去负债之和。所有币种统一保留最多两位小数，新录入金额四舍五入到 0.01；切换币种不改变金额精度。金额必须有限且绝对值不大于 `Number.MAX_SAFE_INTEGER / 100`。

配置目标包含 `cash`、`fixed`、`fund`、`gold`，每项满足 `0 ≤ min ≤ max ≤ 100`，允许 0。保存与导入使用相同校验规则。

## 余额变动记录

更新金额只修改选中的账户，保存录入的余额和与前值的差额。变动原因和备注可留空，默认原因是“余额更新”。金额未改变时不新增重复记录。

新记录包含 `id`、`assetId`、`owner`、`date`、`assetName`、`diff`、`type`、`desc`、`isLiability` 和 `isIncome`。`diff` 是账户余额的实际增减，对资产和负债使用同一符号规则。`isIncome` 仅来自用户明确选择的“计入收益”原因；未选择原因不计入已记录收益。

旧备份中的 `pairedAssetId`、`pairedOwner`、`pairedDiff`、`interestPaid`、`pendingCheck`、`netImpact` 等附加字段原样保留，仅用于备份兼容，不参与计算或展示。近期记录按记录本身的 `owner` 筛选。

## 保存与恢复

首次访问没有本地数据时只初始化空账本，不写入示例资产、流水或历史；首次保存操作才写入浏览器存储。已有账本不会因升级自动清空，也不会自动识别并删除旧示例内容。

示例预览仅在内存中构造独立状态，期间禁止写入、导入和导出。返回时恢复进入前的账本和查看选项；刷新后重新读取自己的本地账本。预览模式不写入备份。

普通写入先构造副本、计算快照并校验，在 localStorage 写入成功后才替换运行时状态。写入失败保留原账户、流水和快照。

读取已有内容失败时保留原始存储，并阻止普通编辑提交。备份恢复在完整校验和用户确认后替换数据。空账本是合法状态，重载不会补入演示资产。

每日快照按本地日期保存，同一天更新同一条记录。日期格式为 `YYYY-MM-DD`，快照满足 `netWorth = totalAssets - liabilities`。
